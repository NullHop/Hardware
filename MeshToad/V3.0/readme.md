## MeshTaod V3

### Hardware Features
* **Radio:** 1 Watt E22P 915MHz LoRa radio with TCXO.
  * **Frontend:** FEM with both PA and LNA.
  * **Filtering:** 902-926MHz Bandpass built-in (RX: SAW filter pre-LNA, SAW filter post-LNA; TX: SAW filter pre-PA, Lowpass filter post-PA).
* **USB-C Interface:** 
  * **Chipset:** CH341 USB to SPI adapter with I2C EEPROM (preprogramed)
  * **Power:** 5V 750ma max

### Software
* **Meshtasticd:** Port of Meshtastic to MacOS, Linux, and OpenWRt
  * **Setup Information:** [https://meshtastic.org/docs/meshtasticd/](https://meshtastic.org/docs/meshtasticd/)
* **pyMC Repeater:** Meshcore repeater package for multiple OS's
  * **Setup Information:** [https://github.com/pyMC-dev/pyMC_Repeater](https://github.com/pyMC-dev/pyMC_Repeater)
